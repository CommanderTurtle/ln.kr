      About ln.kr
      
    

    

      
No account. No paste database. No server payload.

      
Turn exact source into
one self-contained link.

      
Code, Markdown, notes, whitespace, line endings, and Unicode survive byte-for-byte. Repeated blocks collapse into references; the browser does everything.

    

    
The payload stays in the URL fragment and is decoded locally. ln.kr retains ha.mr’s BigInt engine and its ASCII, QR, and emoji alphabets, then adds an exact code-and-text grammar above it.

  

  

    Document payloads stay in fragments—there is no paste database.
    Codec lineage: p2r3/ha.mr
